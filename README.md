### 운영체제 교재 기반 RAG 공동연구

운영체제 교재 OSTEP 기반 RAG 공동연구에서 키워드가 교재의 개념 파트 사이에 어떻게 분포하는지 시각화하고, 결과 해석에 참여했습니다. 공동연구에서는 임베딩 벡터를 비교해 모델 규모가 커질수록 개념군이 더 뚜렷하게 분리되는 경향을 관찰하고, 이러한 구조적 특성과 검색 품질을 함께 분석했습니다. 관련 데이터 작업으로 Text-to-SQL 입력 데이터 정제도 수행했습니다.

<br>

### OpenSSD 할당 정책 공동연구

Cosmos+ OpenSSD 환경에서 Channel·Way·Page 우선 할당 정책의 순차 I/O 대역폭과 지연시간을 비교한 공동연구에 참여했습니다. **실험에서는 순차 쓰기에 Channel 우선, 순차 읽기에 Way 우선 정책이 가장 효율적이었습니다.** 읽기·쓰기 워크로드에 따라 유리한 정책이 달라져, 단일 할당 정책으로 모든 워크로드를 최적화하기 어렵다는 점을 확인했습니다.

<br>

### RocksDB Compaction 분석

시스템소프트웨어 연구실의 공동연구로 Leveled·Universal·FIFO Compaction의 성능을 비교하고, 실험 결과를 표와 그래프로 정리했습니다. **해당 실험에서 FIFO는 높은 쓰기 처리율을 보였지만 읽기 히트율이 낮았습니다.** 오래된 데이터를 삭제하는 정책 특성을 함께 분석해, 처리율만으로 성능을 판단하기 어렵고 조회 성공률과 데이터 보존 요구도 고려해야 함을 확인했습니다. 연구 결과를 논문으로 작성해 **KCC 2025에서 제1저자로 발표**했습니다.

`RocksDB` `db_bench` `Bash` `Python`
